Test Mode

When ON, every order placed on the live customer site is tagged as a test order — it's skipped from the confirmation email and hidden from the restaurant admin's order dashboard entirely. Only superadmins can see this setting or view test orders, so you can walk through the full customer → kitchen flow yourself without staff noticing or real orders getting mixed in.

Current status

This is a global switch. While ON, real customers browsing the live site will also have their orders tagged as test orders and hidden from the kitchen. Turn it off as soon as you're done testing.
